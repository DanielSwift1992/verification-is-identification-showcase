# Drawing v0.1

DocumentKit owns this reading. `./drawing <world-id>` compiles the declared source files with the actual Swift modules and reads the named root's `typeName` in a child process. Its JSON output contains either SVG text, an addressed refusal, an explicitly un-compared case, or an execution failure. `./drawing request.json` accepts another world's request with source paths relative to that JSON file. It is an ordinary compiler driver, not a Swift interpreter. Input source must be trusted to execute; the subprocess is isolation from crashes, not a security sandbox.

`Worlds/Playground/drawing.json` declares each drawable root and its SwiftPM target, including the explicit At scale remainder. SwiftPM supplies the complete source selection, imports/dependencies and compilation settings; the reader imports the actual compiled target. The source list in the frozen manifest is a derived receipt, not a second authored selection. `requests.json` adds the controls. `manifest.json` and `cases/*.svg` are authored with `./drawing --freeze` and reviewed as one change. `./drawing --check` recompiles and executes every available case, verifies the explicit un-compared residue, and checks their input digests, exact outcomes, exact SVG bytes and well-formed XML. It is part of `check.sh`'s build law. A newly trapping drawable makes this law red with its source/root address. A runtime signal without a recognized owner precondition is an error, never evidence of a semantic refusal. Compiler failure and budget exhaustion likewise cannot pass as a refusal.

The input byte string is the listed sources, in order, joined by one LF byte. `inputSHA256` is SHA-256 of that exact byte string (including the original terminal LF bytes). `sources` retains the addresses. The reading is keyed by the input hash **and** the declared root; the complete owner environment is the showcase commit containing this contract and its `Package.swift` theory pin. `owner` additionally records the actual source digests of the native DocumentKit, Organization, VerificationIsIdentification and Alphabet modules; a different local override cannot silently stand for the pinned owner. A port must not compare a different input or silently substitute local sources. `svgSHA256` hashes the exact UTF-8 output; `output` names those same bytes. No XML canonicalization, whitespace normalization or rendering tolerance is used. Refusal equality is `(status, code, address)`; compiler stack traces are deliberately not portable contract data.

The normal budget is 600 seconds for DocumentKit preparation, then 120 seconds per requested target build and probe link, and 20 seconds to read it. A simple DocumentKit request does not build the company. At scale is explicitly **not compared**: the owner now materializes its 12800-person company, page and geometry under `Worlds/Playground/Scale` using `Tools/Playground/generate-company.js`. The full company court and addressed controls run in `Checks/Playground/scale.sh`; the source hashes bind the separate Drawing remainder. The Scale page has not been compiled or read natively. A prior 1200-second compile attempt did not produce native SVG. No parity or usable drawing is claimed for that case. Consumers must expose this state instead of calling it compared. This version does not claim coverage of arbitrary DocumentKit forms.

The Half/Rest positive and refusal twins execute the owner's integer preconditions. The XML twins are valid text and attribute content, including angles, ampersands and both quotation marks: the owner escapes at serialization, after measuring the original text. They are not rejected merely for containing these characters. The check's negative output controls reject the unescaped-text and unescaped-attribute twins. The generic `TermText` control additionally checks the parsed text content, so well-formed but doubly escaped XML fails. `TermText` now yields original characters; Vector owns their serialization. Atom additionally exercises generic-looking prose; Light exercises generic rule attributes. Succ's inherited count stays one; the empty Typewriter has zero text lines.

Read me keeps its eighth-second animation: integer ticks are read through `Seconds<Ticks, Frequency>`, rather than passing fractional values through integer `Half`. Light's note receives the 296-pixel remainder after the row's 216 fixed pixels; its height is measured at that same width. Neither fix changes the page's text, experiment, or count semantics.

A consumer reports `compared` only when both the exact input hash/root and its actual result match a native case. A supported new or edited input is `port-under-contract`: this finite contract holds for the port, but the owner has not read those bytes. An explicitly un-compared case reports `not-compared` with its reason. Output refusal/unsupported is separate from this comparison status; a successful court verdict cannot upgrade either. These names align with the T-0038 publication contract.

An external request needs only a root, its address and the source files (relative to the JSON file):

```json
{"root":"MyArt","address":"Page.swift#MyArt","sources":["Dictionary.swift","Page.swift"]}
```

Optional `dependencies` lists native module names to link; the default is VerificationIsIdentification, Alphabet and DocumentKit. A request may instead name a `target` in this package and a `root`; SwiftPM then owns its source selection. The command uses Python 3 and the package's Swift toolchain.

`contract.json` is the portable input generated and checked by the same native reading. It carries source-byte hashes and exact SVG bytes alongside the manifest outcomes. DrawingProfile.Contract names its ordinary taken row in record format 2. The profile consumer verifies that row before comparing a current reading; editing bytes or adding semantic input removes an exact-case match.

The portable contract also records the profile and its palette, bindings, font, metrics and license hashes. A changed profile environment is port-under-contract even when source SVG bytes match. The palette case executes the actual Site/Palette.swift through DocumentKit. XYZRatioWrite carries a positive integer coordinate scale at the output door, preserving the previous profile CSS thousandths without treating Half<Unit> as a fractional count. DrawingBindings.Projection now names that native XYZRatioWrite projection of its declared Value.
